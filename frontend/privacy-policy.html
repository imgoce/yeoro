"여로(yeoro)"(이하 "서비스")는 세종시 무장애 여행 큐레이션을 제공하는 서비스로, 이용자의 개인정보를 소중히 다루며 아래와 같은 기준으로 개인정보를 처리합니다.

1. 수집하는 개인정보 항목

구분수집 항목수집 시점
카카오 로그인 이용 시 카카오 계정 고유 식별자, 닉네임 카카오 로그인 진행 시
게스트 이용 시 기기별로 자동 생성되는 임의 식별자(로그인 정보 아님) "게스트로 둘러보기" 최초 이용 시
위치 정보 기기의 GPS 좌표(위도/경도) 브라우저 위치 접근 권한을 허용한 경우, 주변 장소 추천 시

2. 개인정보 저장 위치 및 방식

현재 버전은 별도의 회원 서버 데이터베이스 없이, 이용자의 브라우저(기기) 내 저장소(localStorage)에만 정보를 저장합니다. 즉 위 1항의 이용 기록·게스트 식별자·마지막 로그인 정보는 이용자의 기기에만 남으며, 서비스 운영자가 별도로 서버에 수집·보관하지 않습니다.

⚠️ 백엔드(회원 DB, 카카오/구글 토큰 교환 서버 등)를 실제로 연동하는 시점에는 이 항목을 서버 저장 방식에 맞게 반드시 다시 작성해야 합니다.

3. 개인정보의 이용 목적

  • 무장애 동선·장소 맞춤 추천 제공
  • 카카오 로그인을 통한 서비스 이용 및 재방문 시 로그인 유지
  • 게스트 이용자의 여행로그(방문 기록) 기기 내 보관
  • 현재 위치 기반 주변 관광지·맛집·의료기관 검색

4. 개인정보의 제3자 제공 및 외부 API 연동

이용자의 위치 좌표(위도/경도)는 아래 외부 서비스에 검색 요청 시 전달됩니다.

제공받는 자제공 항목목적
카카오(Kakao) — 로그인 및 카카오맵로그인 인증 정보, 위치 좌표카카오 계정 로그인, 주변 맛집/의료기관 검색
한국관광공사 공공데이터포털(data.go.kr)위치 좌표주변 관광지·축제·웰니스 정보 조회

그 외의 목적으로 개인정보를 외부에 제공하지 않습니다.

5. 개인정보의 보유 및 삭제

  • 브라우저 저장소(localStorage)에 저장된 정보는 브라우저의 사이트 데이터 삭제 또는 앱/브라우저 삭제 시 함께 삭제됩니다.
  • 서비스 내 "로그아웃" 기능을 사용하면 로그인 세션 정보가 즉시 삭제됩니다.
  • 삭제·문의를 원하실 경우 아래 문의처로 연락해주시면 안내해드립니다.

6. 아동의 개인정보

서비스는 "영유아 동반 부모 코스 모드"를 제공하지만, 이는 보호자(성인)가 자녀와 함께 이용하기 위한 화면 구성일 뿐이며 영유아가 직접 개인정보를 입력하거나 서비스를 단독으로 조작하는 것을 전제하지 않습니다.

7. 이용자의 권리

이용자는 언제든지 아래 문의처를 통해 자신의 정보 확인·삭제를 요청할 수 있습니다.
