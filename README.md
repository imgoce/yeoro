# yeoro (여로)

**5060 액티브 시니어**와 **영유아 동반 가족**을 위한 세종시 여행 앱입니다.

관광명소·음식점·축제·의료기관을 **무장애 기준(휠체어·유모차 진입 가능 여부 등)** 으로 골라서
오늘 날씨와 현재 위치에 맞는 여행 코스를 만들어 줍니다.

---

## 어떤 앱인가요?

> 여행지를 고르고 → 담고 → 길을 찾는 것까지, **앱 하나로** 끝납니다.

```
 앱 켜기 → 약관 동의 → 로그인 → 관광지 둘러보기 → 장바구니에 담기 → 일정 만들기 → 길찾기
   (한 번 동의하면 안 뜸)  ↘ 두 번째부터는 자동 로그인으로 바로 홈
                        ↘ 또는 "날씨 맞춤 추천" 한 번으로 코스 자동 생성
```

### 이런 점이 다릅니다

| | 설명 |
|---|---|
| 🦽 **무장애 중심** | 휠체어·유모차로 갈 수 있는 곳 위주로 안내 |
| 📍 **세종시만** | 내 위치가 어디든 **세종시 안의 장소만** 보여줌 |
| 🌤️ **날씨 맞춤** | 비 오면 실내로, 눈 오면 미끄럼 주의 + 이동 짧은 코스로 자동 변경 |
| 🚗 **정확한 소요시간** | 카카오 길찾기와 **똑같은 기준**으로 계산 (직선거리 ❌) |
| 👀 **읽기 편한 화면** | 글씨 크기 4단계 · 글씨체 2종 · 어두운 모드 |
| 📴 **끊겨도 동작** | 인터넷·API가 막혀도 기본 데이터로 앱이 멈추지 않음 |

## 주요 기능

### 1. 앱에 들어가기

```
서버 준비 → 약관 동의 → 로그인 → 위치 안내 → 홈
```

**약관 동의** — 개인정보처리방침·이용약관에 동의해야 들어갈 수 있습니다.
각 항목의 `상세보기`를 누르면 문서 전문이 뜨고, **한 번 동의하면 다음부터는 뜨지 않습니다.**
문서는 앱 안에 넣어 두어(`js/policy-data.js`) 인터넷이 느려도 즉시 열립니다.
나중에 다시 보려면 **MY → 약관 및 정책**.

**로그인 (3가지 중 선택)**

| 방식 | 설명 |
|---|---|
| **카카오 로그인** | 카카오톡이 있으면 바로 로그인 |
| **10초 회원가입** | 이메일·비밀번호만으로 가입 |
| **게스트** | 가입 없이 바로 둘러보기 (서버가 늦으면 2.5초 뒤 기기 안에서 진행) |

> **자동 로그인** — 이전에 로그인했으면 로그인 화면 없이 바로 홈으로 들어갑니다.
> 저장된 정보로 화면을 먼저 띄우고 토큰 확인은 뒤에서 하므로 기다림이 없고,
> 만료됐으면 그때 안내하고 로그인 화면으로 돌아갑니다. 로그아웃·탈퇴하면 기록이 지워집니다.

### 2. 홈 화면

- 좌측 상단 **로고 + 여로**
- **날씨 배너** — 현재 날씨에 따라 배너 색이 바뀌고 `☀️ 오늘 세종시 28.3°C 맑음`으로 표시
- **바로가기 아이콘 5개** — 관광지 · 음식점 · 축제 · 병원 · 맞춤코스
- **세종 대표 명소** — 사진 카드 가로 스크롤(10곳), 눌러서 정보 보기 · 하트로 장바구니에 담기

하단바는 **홈 · 추천일정 · 장바구니 · 여행로그 · MY** 다섯 칸이고,
장바구니 아이콘 오른쪽 위에 **담긴 개수**가 빨간 숫자로 붙습니다.

### 3. 장소 둘러보기

- **관광명소 · 음식점 · 축제 · 의료기관** 네 가지 카테고리
- 상단 **통합 검색** — 네 카테고리를 한 번에 검색
- 카드마다 **🚗 약 N분 (Nkm)** — 실제 도로 기준 소요시간
- **[ℹ️ 정보]** 버튼 — 영업정보·도로명주소·카카오맵 상세 페이지

**여러 출처를 합치되 중복은 뺍니다.** 한국관광공사와 카카오맵에 같은 가게가 양쪽 다 있는 경우가 많아,
이름을 정규화(괄호·지점 표기 제거)해 비교하고 **100m 안에서 이름이 겹치면 하나로 합칩니다.**

| 카테고리 | 합치는 출처 | 현재 표시 수 |
|---|---|---|
| 관광명소 | 관광공사(관광지·문화시설·레포츠·여행코스·웰니스) + 카카오맵 + 직접 고른 목록 | 49곳 |
| 음식점 | 관광공사(음식점) + 카카오맵(음식점·카페) + 직접 고른 목록 | 102곳 |
| 축제 | 관광공사(축제) + 카카오맵 키워드 | 6곳 |
| 의료기관 | E-Gen 응급의료 + 심평원 병원정보 + 카카오맵 | 18곳 |

- **카페**는 프랜차이즈를 자동으로 뺍니다 (`○○점` 형태·브랜드 목록·카테고리 깊이로 판별)
- **축제**는 올해 열리는 것만 남깁니다
- 조치원 일대를 중심으로 **직접 고른 50곳**(음식점·카페·명소)을 더해 두었습니다

#### 📍 세종시 범위 제한

내 위치가 세종 어디에 있든, **세종시 밖 장소는 보여주지 않습니다.**

```
카카오 검색  → rect=127.05,36.4,127.42,36.76   (세종시를 감싸는 사각형)
합친 뒤 확인 → 주소가 "세종특별자치시"로 시작하는가
              주소가 없으면 좌표로, 둘 다 없으면 제외
```

예전에는 내 위치 기준 반경 20km로 찾아서 공주·청주·대전 경계가 섞여 들어왔습니다.
가까운 순 정렬은 좌표로 따로 하므로 정렬 품질은 그대로입니다.

### 4. 일정 만들기

- **장바구니**에 담고 → 현재 위치 기준 가까운 순으로 자동 정렬
- 담으면 하단바 위에 **`N개의 장소가 담겼어요`** 가 잠깐 떴다 사라집니다 (2.2초)
- 장바구니 안에서 **바로 검색해 추가** 가능
- **🚗 전체 경로 길찾기** — 여러 곳을 경유지로 묶어 한 번에 안내

**추천일정**에서는 **무장애 코스 · 날씨맞춤 코스 · 랜덤 코스** 중에 고를 수 있고,
**맞춤코스**는 장소 수를 직접 정합니다.

| 여행 유형 | 고를 수 있는 장소 수 |
|---|---|
| 당일치기 | 3 · 4 · 5 · 6곳 |
| 1박 2일 | 5 · 6 · 7 · 8 · 9 · 10곳 |

고른 개수에 맞춰 하루 흐름대로 순서가 짜이고, 고르는 자리 바로 아래에 미리 보여줍니다.

```
관광지 → 음식점 → 카페 → 관광지                    (4곳)
관광지 → 음식점 → 카페 → 관광지 → 관광지 → 음식점    (6곳)
```

### 5. 🌤️ 날씨 맞춤 코스

기상청 실시간 날씨를 읽어 코스를 자동으로 바꿔줍니다.

| 날씨 | 추천 방식 |
|---|---|
| ☀️ 맑음 | 야외 명소 위주 |
| 🌧️ 비 | 젖지 않는 **실내** 위주 |
| ❄️ 눈 | **이동 짧은 실내** + "미끄럼 주의" 안내 |
| 🥵 폭염 / 🥶 한파 | 실내 위주 |

홈 화면 배너에 현재 날씨가 표시되고, **날씨에 따라 배너 색도 바뀝니다.**

### 6. 여행 로그

- 다녀온 곳을 날짜별로 기록
- **[전체 / 내가 담은 곳 / 추천받은 곳]** 필터
- 이름·카테고리·날짜로 검색

### 7. MY

| 항목 | 내용 |
|---|---|
| 글씨 크기 | 작게 · 보통 · 크게 · 아주 크게 |
| 글씨체 | 기본 고딕체 · 명조체 |
| 화면 모드 | ☀️ 밝은 모드 · 🌙 어두운 모드 |
| 약관 및 정책 | 개인정보처리방침 · 이용약관 다시 보기 |
| 데이터 출처 | 사용한 공공데이터 출처 표기 |
| 회원탈퇴 | 계정과 함께 **여행로그·장바구니·북마크·리뷰**를 모두 삭제 |

| **한국관광공사** 무장애 여행정보 | 휠체어·경사로·엘리베이터 등 무장애 시설 |
| **한국관광공사** 웰니스 관광정보 | 힐링 여행지 |
| **기상청** 초단기실황 | 날씨 맞춤 코스 |
| **카카오맵** | 장소 검색 · 지도 |
| **카카오내비** | 소요시간·거리 계산, 길찾기 |
| **국립중앙의료원** E-Gen | 응급의료기관 |
| **건강보험심사평가원** | 병원 정보 |

앱 안에서도 **MY → 데이터 출처**에 `출처: ⓒ한국관광공사` 형식으로 표기해 두었습니다.

> 🔑 **API 키를 넣지 않아도 앱은 정상 동작합니다.** (기본 데이터로 대체)
>
> 무장애 정보는 호출 한도(429)에 걸리면 목록 표시가 20초 넘게 막히던 문제가 있어,
> **앱에 넣어 둔 자료(25곳)를 먼저 보여주고 실제 API는 뒤에서 받아 다음 실행에 반영**합니다.

## 기술 스택

| 영역 | 사용 기술 |
|---|---|
| 프론트엔드 | Vanilla JS(ES6+), HTML5, CSS3, Bootstrap 5 |
| 백엔드 | FastAPI, SQLAlchemy, Pydantic v2, python-jose, httpx |
| 데이터베이스 | SQLite(로컬) / PostgreSQL(배포) |
| Android | Kotlin, WebView, Kakao SDK, Custom Tabs |
| 배포 | Docker, Google Cloud Run |

프레임워크 없이 **순수 웹 표준**으로 만들어, 별도 빌드 과정 없이 브라우저에서 바로 실행됩니다.

## 시작하기

### 1. 화면 미리보기 (제일 간단)

```bash
cd frontend
python tools/live_server.py
```

브라우저에서 **http://localhost:5500** 접속 → 파일을 저장하면 자동으로 새로고침됩니다.
(백엔드도 함께 자동 실행됩니다)

### 2. API 키 넣기 (선택)

`frontend/js/config.local.example.js` 를 복사해서 `config.local.js` 로 만들고 키를 채우세요.
이 파일은 `.gitignore` 처리되어 **깃허브에 올라가지 않습니다.**

```js
API_CONFIG.DATA_GO_KR_KEY = '공공데이터포털 키';   // 관광·날씨·의료
API_CONFIG.KAKAO_REST_KEY = '카카오 REST 키';      // 지도 검색
API_CONFIG.KAKAO_JS_KEY   = '카카오 JavaScript 키'; // 지도 표시
API_CONFIG.KAKAO_NAVI_KEY = '카카오 REST 키';      // 소요시간·길찾기
```

| 키 | 발급처 |
|---|---|
| 공공데이터포털 | [data.go.kr](https://www.data.go.kr) — 관광공사·기상청·의료 서비스 신청 |
| 카카오 | [developers.kakao.com](https://developers.kakao.com) |

> 키가 없어도 앱은 기본 데이터로 정상 동작합니다.

### 3. 안드로이드 앱 만들기

앱은 `android/app/src/main/assets/www` 안의 화면을 띄웁니다.
**화면을 고쳤으면 먼저 복사한 뒤** 빌드하세요.

```bash
cp -r frontend/js/*.js   android/app/src/main/assets/www/js/
cp -r frontend/css/*.css android/app/src/main/assets/www/css/
cp frontend/index.html frontend/privacy-policy.html frontend/terms.html \
   android/app/src/main/assets/www/

cd android
./gradlew assembleDebug
```

만들어진 파일: `android/app/build/outputs/apk/debug/app-debug.apk`

> `assembleRelease`로 만든 파일은 **서명이 없어 기기에 설치되지 않습니다.** 테스트에는 `assembleDebug`를 쓰세요.
> `JAVA_HOME`이 없다는 오류가 나면 안드로이드 스튜디오에 들어 있는 JDK를 가리키면 됩니다
> (`C:\Program Files\Android\Android Studio\jbr`).

`android/local.properties` 에 카카오 네이티브 앱 키가 필요합니다 (이 파일도 커밋되지 않습니다).

```
KAKAO_NATIVE_APP_KEY=카카오_네이티브_앱_키
```

### 4. 약관 문서를 고쳤을 때

`frontend/privacy-policy.html` · `frontend/terms.html` 을 고친 뒤 아래를 돌리면
앱 안에 들어가는 `frontend/js/policy-data.js` 가 다시 만들어집니다.

```bash
python tools/build-policy-data.py
```

### 5. 서버에 배포하기

**[DEPLOY.md](DEPLOY.md)** 에 복사해 붙여넣는 방식으로 정리해 두었습니다. (약 30분)

```
1단계 저장소 만들기 → 2단계 서버에 올리기 → 3단계 열쇠 넣기 → 4단계 카카오에 알리기
```

## 🔒 API 키 관리

**키는 절대 깃허브에 올라가지 않습니다.** 아래 파일에만 저장되며 모두 `.gitignore` 처리되어 있습니다.

| 키 종류 | 저장 위치 |
|---|---|
| 공공데이터·카카오 (화면용) | `frontend/js/config.local.js` |
| 백엔드용 | `backend/.env` |
| 카카오 네이티브 앱 키 | `android/local.properties` |

배포 환경에서는 서버 환경변수로 주입되어, **앱 파일 안에도 키가 들어가지 않습니다.**
